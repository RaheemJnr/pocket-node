# Pocket Node Privacy Policy

**Last updated: 2026-05-21**

Pocket Node is a self-custody cryptocurrency wallet for the Nervos CKB blockchain. The App is designed with privacy as a core principle: it runs an embedded light client directly on your Android device and does not communicate with any servers operated by us.

This Privacy Policy explains what data the App handles, how it is stored, and what permissions it requires. The short version: we collect nothing, store everything locally, and give you full control over your data.

## Data we collect

**None.** Pocket Node does not collect, transmit, or store any personal data on external servers. Specifically:

- No account creation or registration is required.
- No email addresses, names, or contact information is collected.
- No analytics, telemetry, or usage tracking of any kind.
- No crash reporting to external services.
- No advertising identifiers or device fingerprinting.
- No IP address logging by any server we operate (we operate no servers).

## Data stored on your device

All data generated by the App is stored locally on your Android device. Nothing leaves your phone unless you explicitly initiate a blockchain transaction. Locally stored data includes:

- **Wallet keys.** BIP39 mnemonic and derived private keys, encrypted at rest with an AES-256-GCM key generated by the Android Keystore and bound to user authentication. On Android 9 and newer, the Keystore key is hardware-backed via the Trusted Execution Environment or Secure Element.
- **Address book contacts.** Names and CKB addresses you add yourself, stored in the App's local Room database.
- **Sync state.** Per-wallet block-height progress markers used by the embedded light client.
- **Cached blockchain data.** Block headers, DAO compensation headers, and matched cell data necessary for the light client to compute your balance and transaction history.
- **App preferences.** Selected network (mainnet or testnet), sync mode, theme choice, and other UI settings.

## Network communications

The App communicates only with the decentralized Nervos CKB peer-to-peer network via the embedded light client. This is necessary to:

- Sync block headers and verify transactions.
- Query cell (UTXO) data to determine your balance.
- Broadcast signed transactions when you send CKB.

These connections are made directly to CKB network nodes, not to any server operated by us. The information exchanged is limited to blockchain protocol data (block headers, cell data, transaction data). Your IP address may be visible to CKB network peers, as is standard for any peer-to-peer blockchain client.

In addition, the App may connect to two specific public services if you opt in:

- **GitHub Releases API** to check for new versions of the App when the in-app updater is enabled. The request is a public unauthenticated read; no identifying information is sent beyond your IP address (visible to GitHub as the request origin).
- **Public CKB block explorer** when you tap a transaction or block link in the App. These open in your phone's browser via Custom Tabs; the explorer operator's privacy policy applies to that session.

## Permissions

Pocket Node requests the following Android permissions:

- **Internet:** required for the embedded light client to connect to CKB peers.
- **Camera (optional):** only when you use the in-app QR code scanner. Camera images are processed locally using an on-device barcode scanner. No images are stored or transmitted.
- **Biometric:** if you opt in, the system biometric prompt is used to authenticate sensitive actions. Biometric data never leaves the device's secure hardware.
- **Install packages (optional):** required only if you install updates through the in-app updater from a GitHub Release. The permission lets the updater hand off the downloaded APK to Android's standard installer. You can revoke it from system settings at any time.
- **Foreground service (sync only):** used by the background sync service to keep the light client running with a visible system notification while the app is backgrounded. No data is exfiltrated; the service only continues the same peer-to-peer communication described above.

## Data deletion

You have full control over your data at all times:

- **Delete wallet:** use the in-app "Delete Wallet" option in Settings to erase a specific wallet's keys, transaction cache, and preferences from your device.
- **Uninstall:** uninstalling the App removes all locally stored data, including keys, contacts, and blockchain data.
- **No remote data:** since no data is stored on our servers, there is nothing to request deletion of externally.

**Important:** before deleting a wallet, ensure you have backed up its 12-word recovery phrase. Once deleted, a wallet can only be recovered using its phrase.

## Children's privacy

Pocket Node is a financial application intended for users aged 18 and older. We do not knowingly target or collect data from children under 18. The App does not collect data from any user regardless of age.

## Third-party services

Pocket Node does not integrate any third-party analytics, advertising, or tracking services. The App does not use:

- Google Analytics or Firebase Analytics
- Crash reporting services (Crashlytics, Sentry, etc.)
- Advertising SDKs
- Social media SDKs
- Push notification services

The only external network communications are the ones listed under "Network communications" above. These are direct, on-device, and limited to the strict functions of the wallet.

## Open source

Pocket Node is fully open source. You can audit the complete source code, including all network communications, data storage, and cryptographic operations, on our [GitHub repository](https://github.com/RaheemJnr/pocket-node).

## Changes to this policy

If we make changes to this Privacy Policy, we will update the "Last updated" date at the top of this page. Since the App collects no data, material changes are unlikely. Any changes will be reflected in the App's next release.

## Jurisdictional notes

- **GDPR (EU / EEA / UK):** Pocket Node does not collect or process personal data, so the App is outside the scope of GDPR Article 4 processing. You have the right to request confirmation that no data about you is held; the answer is always "none."
- **CCPA / CPRA (California):** Pocket Node does not sell, share, or collect personal information as defined in the CCPA. The App has no opt-out flow because there is nothing to opt out of.
