Pocket Node 是第一款在你的设备上直接运行完整 CKB 轻客户端的 Android 钱包。你的手机就是节点，无需向他人的服务器发起请求。

为什么选择 Pocket Node

大多数 CKB 钱包,包括那些自称非托管的钱包,都依赖远程索引服务来查询余额。Pocket Node 不依赖这些。应用内嵌的轻客户端直接对接 Nervos 网络,验证区块头和 Cell 数据。无分析跟踪。无遥测。无远程回传。

主要功能

- 内嵌 CKB 轻客户端 (基于 Rust,通过 JNI 在进程内运行),负责余额查询、历史记录和交易广播
- BIP39 12 词助记词,首次运行时本地生成;也支持导入已有钱包
- 多钱包与 HD 子账户。单次安装支持任意数量钱包。一个母钱包助记词即可恢复所有派生账户
- 原生 Nervos DAO 支持:存款、两阶段提款、按 Cell 的补偿追踪 (基于链上区块头 DAO 字段计算)
- 通讯录支持智能建议、发送页自动补全、以及发送成功后的保存联系人提示
- Argon2id PIN 派生,内存成本 64 MB。24 小时累积衰减锁定;失败 10 次后永久锁定
- 生物识别解锁基于 Android Keystore。交易签名和助记词显示采用按操作认证
- 四种同步模式:新钱包 (即时)、近期活动 (约 2 分钟)、自定义区块高度 (含浏览器深链)、完整历史
- 同步停滞检测,旧钱包卡住时一键切换 Recent 模式恢复
- 应用内更新 (适用于从 GitHub Releases 安装的用户)
- 二维码扫描收款地址
- 主网与测试网,可在设置中切换
- 深色模式:系统、浅色、深色三种选项

密钥存储

私钥使用 AES-256-GCM 加密,密钥由 Android Keystore 生成并与用户认证绑定。Android 9 及更新版本上,Keystore 密钥通过可信执行环境 (TEE) 或安全元件硬件支持。密钥无法从设备中导出。交易签名在本地完成;私钥不会离开手机。

开源

Pocket Node 在 CKB 社区 DAO 资助下开发。基于 MIT 许可证完全开源。每一行代码,包括 Rust 轻客户端、JNI 桥接和 Kotlin 应用,都可以在 GitHub 上审计。

系统要求

Android 8.0 (Oreo) 或更高版本。应用本身约 100 MB 存储空间,加上轻客户端数据 50 MB 至 200 MB (取决于同步模式)。
