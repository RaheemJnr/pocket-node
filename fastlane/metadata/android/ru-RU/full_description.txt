Pocket Node — первый Android-кошелёк, который запускает полноценный лёгкий клиент CKB прямо на вашем устройстве. Ваш телефон является узлом, а не запросом к чьему-то серверу.

ПОЧЕМУ POCKET NODE

Большинство кошельков CKB, в том числе позиционируемых как некастодиальные, полагаются на удалённый индексатор для получения баланса. Pocket Node так не работает. Встроенный в приложение лёгкий клиент сам сверяет заголовки блоков и данные ячеек напрямую с сетью Nervos. Без аналитики. Без телеметрии. Без обратных запросов.

ФУНКЦИИ

- Встроенный лёгкий клиент CKB (на Rust, в том же процессе через JNI) для баланса, истории и широковещательной рассылки транзакций
- Восстановительная фраза BIP39 из 12 слов, генерируется локально при первом запуске; импорт существующих кошельков также поддерживается
- Поддержка нескольких кошельков и HD-субаккаунтов. Неограниченное число кошельков на одну установку. Одна родительская фраза покрывает все производные счета
- Нативная поддержка Nervos DAO: депозит, двухфазный вывод, отслеживание компенсации по каждой ячейке на основе DAO-полей заголовков блоков
- Адресная книга с подсказками, автодополнением на экране отправки и предложением сохранить контакт после успешной отправки
- Деривация PIN-кода через Argon2id с памятью 64 МБ. Накопительная блокировка с 24-часовым затуханием; постоянная блокировка после 10 неудач
- Биометрическая разблокировка на основе Android Keystore. Аутентификация на каждую операцию для подписи транзакций и показа фразы восстановления
- Четыре режима синхронизации: Новый кошелёк (мгновенно), Недавняя активность (около 2 минут), Произвольная высота блока (со ссылкой на обозреватель), Полная история
- Детектор зависания синхронизации с восстановлением в одно касание для старых кошельков
- Встроенное обновление приложения для тех, кто устанавливает из GitHub Releases
- Сканер QR-кодов для адресов получателей
- Mainnet и testnet, переключаются в Настройках
- Тёмная тема с вариантами Системная, Светлая и Тёмная

ХРАНЕНИЕ КЛЮЧЕЙ

Приватные ключи шифруются ключом AES-256-GCM, сгенерированным Android Keystore и привязанным к аутентификации пользователя. На Android 9 и новее ключ Keystore аппаратно защищён через Trusted Execution Environment или Secure Element. Ключи нельзя извлечь с устройства. Подпись транзакций выполняется локально; приватные ключи не покидают телефон.

ОТКРЫТЫЙ КОД

Pocket Node разработан на грант сообщества CKB Community DAO. Полностью открытый код под лицензией MIT. Каждая строка кода, включая лёгкий клиент на Rust, JNI-мост и приложение на Kotlin, доступна для аудита на GitHub.

ТРЕБОВАНИЯ

Android 8.0 (Oreo) или новее. Около 100 МБ свободного места для приложения и ещё 50 МБ — 200 МБ для данных лёгкого клиента в зависимости от режима синхронизации.
